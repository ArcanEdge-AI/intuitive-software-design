# Scenario 5 — Expert Software

## Prompt

Review a deliberately dense weekly crew-scheduling grid for dispatchers who use it all day. It shows 42 crews across seven days, trade abbreviations familiar to dispatchers, utilization, conflicts, filters, saved views, visible actions, and discoverable keyboard shortcuts. Editing a crew currently preserves filters and scroll position. Evaluate intuitiveness without penalizing appropriate professional domain complexity or density.

## Acceptance gates

- Establishes dispatchers as expert intended users.
- Does not reduce a score merely because of density, abbreviations, or specialized workflow.
- Evaluates hierarchy, recognition, prediction, context, state, accessibility, and mastery using evidence.
- Names strengths to preserve.
- Uses `NE` for behavior that the prompt does not establish.
