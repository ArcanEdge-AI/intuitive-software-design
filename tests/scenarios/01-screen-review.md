# Scenario 1 — Screen Review

## Prompt

Use Intuitive Software Design to review this single project screen for a first-time project manager. The screen title is `Project`. It shows the customer and due date, three unlabeled icon buttons, a clear `Create estimate` button, and a `Draft` badge. A screenshot is the only evidence. Separate UI, Flow, and Feel where evidence permits; do not invent interaction behavior.

## Acceptance gates

- Classifies the request as REVIEW.
- Distinguishes UI, Flow, and Feel.
- Uses specific observable evidence.
- Treats interaction behavior, recovery, and other screenshot-invisible Feel evidence as `NE` or explicitly unverified.
- Does not turn the result into an aesthetic critique.
