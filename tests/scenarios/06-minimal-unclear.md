# Scenario 6 — Minimal but Unclear UI

## Prompt

Review a visually minimal project screen for occasional project managers. Its only actions are three unlabeled glyphs: a sparkle calculates pricing, a diamond duplicates the project, and an arrow sends a proposal. The current state is conveyed by a small green dot. Explain the difference between visual simplicity and cognitive simplicity and propose the smallest complete improvement.

## Acceptance gates

- Recognizes that minimal visual design can still create Interpretation and Prediction friction.
- Distinguishes visual, interaction, and cognitive simplicity.
- Flags unlabeled controls and color-only state with accessibility implications.
- Preserves the basic screen rather than automatically redesigning it.
- Recommends labels or equally reliable accessible names/cues plus visible semantic state.
