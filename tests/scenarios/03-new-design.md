# Scenario 3 — New Design

## Prompt

Use Intuitive Software Design to help design a project-creation feature that does not yet exist for construction project managers. A project needs a name and customer before it can exist; scope and team can be added later. Define the flow, decisions, states, recovery, and measurable acceptance. Do not pretend there is an existing screen to audit.

## Acceptance gates

- Classifies the request as DESIGN.
- Uses the project manager's mental model rather than a database-record sequence.
- Applies the Intuitive Software Loop proactively.
- Controls Decision Density and keeps deferred settings discoverable.
- Defines applicable empty, pending, success, failure, and recovery states.
- Labels proposed behavior as a design hypothesis rather than observed usability evidence.
